# 🚑 Smart Emergency Flutter App

A Flutter-based mobile application designed to store and access critical patient information quickly during emergencies.

## 📱 Features
- Store patient details
- Track medications and drug interactions
- Quick patient lookup
- Edit patient records
- Fast emergency access

## 🛠️ Tech Stack
- Flutter
- Dart

## 🚀 How to Run
git clone https://github.com/nagesh1311/smart-emergency-flutter-app.git
cd smart-emergency-flutter-app
flutter pub get
flutter run
